# 一键启动 QuickLaunch v1.2.0

> 勾选一批程序，点一下，**按各自的间隔依次打开**。
> Windows 桌面小工具，单文件 162 KB，零依赖，绿色免安装。

这是**首个公开发布版**，把两轮内部迭代（1.0 / 1.1）合并发布。

---

## 这个版本修掉了什么

### 启动更可靠

- **`.lnk` 条目直接按"双击快捷方式"启动** —— 保留快捷方式里的参数、起始位置、AppUserModelID、提权标记，而不是只拿解析出来的 exe 路径
- **启动后 1.2 秒存活检查** —— 进程秒退会记录退出码；退出码非 0，或"退出码 0 但其实没在运行"时，自动改用 `ShellExecute` 重试一次
- **"已在运行"两级判定** —— 完整路径精确匹配 + 进程名兜底，缩在托盘里的实例也能识别
- 不再手动 `spawn explorer.exe`（部分系统会报 `0xc0000142`），改成把文件夹路径交给 shell

### 配置不会再"自己换一套"

- **便携模式**：exe 旁边放一个 `portable.txt`，配置就固定在 `.\config\`，完全不碰 `%APPDATA%`
- **位置固定化**：一旦某个位置已经有 `config.json`，就永远用它 —— 不再因为"此刻写不进去"而静默切换到另一个文件
- 两处都存着配置时，启动日志**红字警告**并给出两份路径
- 保存失败时明确报出目标路径（以前是静默失败，只能从日志里翻）

### 两个陷阱，程序现在会自己说出来

| 情况 | 程序会做什么 |
|---|---|
| 以**管理员**身份运行 | 日志顶部列出三个副作用：拖放失效 / 子程序继承提权 / 文件关联失效 |
| 放在**受限目录**里运行 | 配置目录不可写时，判定为"运行在受限环境"并给出迁移建议 |

这两种情况的表现极具迷惑性（程序能打开、但被它启动的程序全起不来、`.md` 双击没反应），以前只能靠猜。

## 下载与安装

1. 下载 `QuickLaunch-v1.2.0.zip`
2. 解压到**普通目录**（例如 `D:\QuickLaunch\`、`E:\软件\QuickLaunch\`）
3. 双击 `QuickLaunch.exe`

> ⚠️ **不要**解压到被安全软件 / 沙箱 / 特殊工具限制过权限的目录。
> 那种目录里运行的程序，它启动的子进程会继承限制、读写不了自己的数据目录，
> 表现为"对象程序打不开、配置存不进去"。
>
> ⚠️ **不要**用「以管理员身份运行」。
> 本程序自身不需要管理员权限；提权后拖放会失效，双击 `.md` 之类文件也会没反应。
> 个别需要提权的程序，启动时会自己弹 UAC。

### 首次运行

列表是空的 —— 本程序**不扫描系统**。把桌面 / 开始菜单里的快捷方式**直接拖进窗口**，
或者点工具栏「添加程序」。每行勾上，设好间隔，点左下角「一键启动」。

## 功能一览

| 功能 | 说明 |
|---|---|
| 勾选启动 | 每行一个勾选框，只启动勾上的 |
| 独立间隔 | 每个程序 1~5 秒可任意填，串行启动不抢磁盘 |
| 手动拖入 | `.lnk` / `.exe` / 文件夹 / `.url` / `.bat` / 任意文档 |
| 分组 | 日常 / 工作 / 系统工具，底栏可单独启动某一组 |
| 不经过 cmd | Win32 `CreateProcess`，快、无黑框、能拿到真实 PID 和错误码 |
| 自动提权 | 需要管理员的程序自动走 `runas` 弹 UAC |
| 跳过重复 | 已在运行时跳过，不重复开第二个 |
| 高 DPI | PerMonitorV2，150% 缩放下文字原生清晰 |
| 日志 | 界面实时查看 + 按天写文件，后台线程不卡界面 |

## 已知问题

1. **未做数字签名** —— 部分机器首次运行会弹 SmartScreen「Windows 已保护你的电脑」，点「仍要运行」即可。介意安全性的可以直接用源码自行编译（`编译.cmd`），本地编译出来的程序不触发该提示。
2. **提权环境下文件关联失效** —— 例如 Obsidian 以管理员运行后，双击 `.md` 打不开。请以普通权限运行本程序。
3. **跨不同缩放比例的显示器**拖动窗口时不会自动重新缩放（.NET Framework 4.8 WinForms 的固有短板），单屏无影响。
